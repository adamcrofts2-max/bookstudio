# Book Studio — Layout Engine Rules

Rules the Layout Engine (Phase 3) must follow. These take precedence over arbitrary
placement whenever a layout decision is required. Beauty, readability and balance are
the highest priorities — the objective is not to fill pages, it's to produce books that
look professionally designed.

## Core Principles
Every page should feel balanced, calm, elegant, readable, intentional, professional.
The reader should never notice the layout — good design becomes invisible.

## Hierarchy
Every page must clearly communicate chapter, section, subsection, body text,
supporting information, captions and footnotes without effort.

## Page Balance & White Space
Whitespace is content — never fill every page. Avoid heavy left/right pages, large
empty areas beside dense paragraphs, crowded corners, competing focal points. Prefer
whitespace over overcrowding.

## Line Length & Paragraph Spacing
Target 55–75 characters per line. Spacing before headings must always exceed spacing
after headings. Maintain vertical rhythm throughout.

## Chapter Openers
Start on a right-hand page. Large heading, generous whitespace, optional hero
illustration/quote/intro paragraph. Never begin immediately with dense text.

## Images & Captions
Place images close to related text; keep captions attached, never split across pages.
Placement priority: hero image → full-width → half-width → inline → gallery →
floating — chosen based on surrounding content, never at random.

## Pull Quotes, Tip/Warning/Fact Boxes
Pull quotes create rhythm — maximum one every 4–6 pages. Tip boxes stand apart with
generous padding and subtle colour. Warnings attract attention without alarm. Fact
boxes never interrupt the primary reading flow, preferring page edges.

## Tables & Lists
Tables never overflow; align numbers and text consistently, avoid excessive borders.
Bullets align perfectly with equal spacing; split long lists where appropriate.

## Widows, Orphans & Page Turns
Never leave single lines at page tops/bottoms, isolated headings, or short paragraphs
stranded on a new page — always rebalance automatically. Avoid ending pages on
incomplete thoughts or awkward sentence breaks.

## Facing Pages
Treat two-page spreads as one composition — the spread, not the page, is the primary
design unit. Balance images, whitespace, typography, colour and visual weight across it.

## Genre Defaults
Educational: more whitespace, clear callouts, illustrations near explanations,
consistent iconography. Children's: large imagery, simple hierarchy, short paragraphs,
illustrations dominate. Coffee Table: large photography, minimal text, premium
whitespace. Nature: organic layouts, natural colours, elegant serif, large margins.
Scientific: accuracy, tables, figures, cross-references, consistent numbering.

## Typography & Colour
Never stretch or distort fonts, never fake bold/italic. Maintain consistent leading and
optical alignment. Colour guides attention and never overwhelms — restrained palettes,
high contrast for body text, accent colours only where meaningful.

## Determinism
Layout regeneration must be deterministic: the same manuscript with the same settings
always produces the same layout. Changing a theme affects presentation only, never
content.

## Design Assistant Rules
When asked to improve a layout, never make random changes — only optimise whitespace,
balance, hierarchy, typography, image placement, caption positioning and visual rhythm.
Only make changes that measurably improve the reading experience.

## Print Quality
Every exported page must meet professional publishing standards: margins, bleed,
typography, image quality, alignment, spacing. No visual defects, no unexpected page
shifts, no clipped content.

## Final Standard
Every page should pass this test: *"If this page appeared in a professionally
published book from a major publisher, would it look out of place?"* If yes, improve
it. Repeat until the answer is no.

## Golden Rule
A beautiful book is not one with the most decoration. A beautiful book is one that
allows the reader to effortlessly enjoy the content. Every layout decision should serve
the reader first.
